- **Last updated:** 2026-07-25

## 1. Summary
A natural-language AI assistant (`/business-brain`) that acts as an evidence-backed chief of staff. It answers workspace questions using grounded data (stores, products, followers, conversations, leads) and falls back gracefully when AI is unavailable.

## 2. Goals
- Let users ask plain-language questions about their workspace.
- Provide concise, evidence-based answers with source context.
- Offer preset prompts for daily briefing and top opportunities.

## 3. Non-Goals
- Proactive push notifications or scheduled briefings.
- Voice input.
- Persistent chat history (MVP keeps conversation in client state).

## 4. User Stories
- As a Store Owner, I want to ask "What should I focus on today?" and get a prioritized list based on my data.
- As a Creator, I want to ask "Which products have no conversations yet?" to find follow-up opportunities.

## 5. Domain Model
- `BusinessBrainQuestion` (value object): question text, optional storeId.
- `BusinessBrainAnswer` (value object): markdown answer, sources list, confidence band, generatedAt.
- `WorkspaceContext` (read-only): summary of KPIs and recent stores used to ground answers.

## 6. Public Contract
- `askBusinessBrainAction(input: {question, storeId?})` returns `BusinessBrainAnswer`.
- `aiQueries.getWorkspaceContext(organizationId)` returns `WorkspaceContext`.

## 7. Data / Persistence
- No new tables. Context is built at request time from existing modules.
- Answers are generated by the existing `AIProvider` interface (`OpenAIProvider`).

## 8. API / UI Surface
- `/business-brain` — client-rendered chat page.
  - Input form with question field.
  - Preset prompts: "What should I focus on today?", "Summarize my workspace", "What content should I create next?".
  - Answer panel with sources and confidence.
- AI Business Brain nav link added to global header.

## 9. External Integrations
- OpenAI API via `AIProvider.complete`. Falls back to deterministic dev reply when `OPENAI_API_KEY` is missing.

## 10. Edge Cases & Failure Modes
- No AI key → deterministic summary generated from workspace context.
- Empty workspace → answer explains what data is missing.
- Question too long → input validation error.

## 11. Security & Privacy
- User can only query workspaces they belong to.
- Store-level context is verified against `organizationId`.
- No secrets or PII are sent in prompts beyond workspace metadata.

## 12. Testing Strategy
- Unit: prompt builder and context formatting.
- Contract: `AIProvider` fallback behavior.
- Integration: question → answer end-to-end with mocked provider.
